# E6：相机 + LiDAR 联合时间错位（3×3 全量网格）

**日期：** 2026-11-04
**状态：** 全部完成 —— 推理 100% 覆盖（零跳过），配对子集评测完成
**模型：** BEVFusion 相机–LiDAR 融合（官方 checkpoint），nuScenes val

## 1. 实验设置

- 网格：相机延迟 k_c ∈ {2, 5, 8}（约 200 / 500 / 800 ms）× LiDAR 延迟 k_l ∈ {1, 3, 6}（约 50 / 151 / 301 ms），共 9 格。
- 相机支路 = T1 语义（换为第 k 个历史相机帧，标定保持当前帧不变）。
- LiDAR 支路 = E2 naive 语义（第 k 个历史 sweep 作为主点云，位姿原样不做运动补偿）。
- 每格资格样本 5719–5869；**全部 9 格都跑到资格上限**（5869 / 5863 / 5719）。
- 配对评测：11 个预测文件（fusion clean、LiDAR-only、9 格）取共同子集，**n = 5719**，官方 nuScenes 检测指标。

## 3. 发现

**3.1 LiDAR 延迟主导一切，相机延迟相对便宜。**
固定相机延迟，LiDAR 从 50 ms  stale 到 301 ms，mAP 掉 **31–33 个点**（如 k_c=2：0.6028 → 0.2922）；固定 LiDAR 延迟，相机从 200 ms stale 到 800 ms 只掉 **约 2–3 个点**（如 k_l=1：0.6028 → 0.5723）。热力图呈明显横向条纹：行（LiDAR 延迟）决定档位，列（相机延迟）几乎不重要。

**3.2 所有联合错位格子都背刺到 LiDAR-only 以下。**
9 格（0.2656–0.6028）全部低于 LiDAR-only 基线 0.6497——包括最温和的 c2_l1（相机 200 ms + LiDAR 50 ms），**比 LiDAR-only 低 4.7 个点**。这比单模态错位背刺早得多：纯相机错位（T1）能容忍约 0.5 s，运动补偿后的 LiDAR 错位（E5）到 ~75 ms 才跌破 LiDAR-only。而 naive（未补偿）LiDAR 一参与进来，融合立刻跌破 LiDAR-only——与 E2 一致（naive k1 ~50 ms 时已低于 LiDAR-only）。相机错位再叠加约 2–3 个点的额外损失。

**3.3 联合错位近似可加，大延迟下略有超加性。**
- c2_l1 相对 fusion clean 的跌幅 8.4 pt（0.6870 → 0.6028）。对应延迟下单模态跌幅之和（各自在自己的配对子集 n = 5856 上测）：E2 naive k1 ≈ 6.1 pt + T1 相机 k2 ≈ 2 pt ≈ **8.1 pt——基本可加**。
- c8_l6 实际跌幅 42.1 pt；E2 naive k6 单独跌 36.7 pt，T1 相机 k8 只跌 ~1.5 pt，和 ≈ 38 pt，实际 42.1 pt——大延迟下轻微**超加性**：LiDAR 几何崩了以后，过期相机特征融合到已损坏的 BEV 锚点上，代价反而比"几乎无影响"更大。（跨实验对比为近似：共同子集不同。）

**3.4 速度和朝向误差爆炸——动态目标拖影的典型特征。**
mAVE 从 0.257（clean）升到全网格 0.42–0.77，mAOE 从 0.30 升到 0.52–0.60；而尺度误差 mASE 几乎不变（0.254 → 0.27），说明错误来自定位/时序，而非尺寸。

## 4. 解读与部署建议

- BEVFusion 的相机支路依赖 LiDAR 深度/几何把图像特征提升到 BEV；过期 LiDAR 会腐蚀这个共享几何锚点，所以 **LiDAR 新鲜度是决定性约束**。部署上优先保证 LiDAR 低延迟（或采用 E5 的自运动补偿，可消除小延迟下的大部分崩溃）。
- 相机延迟预算相对宽松：只要 LiDAR 新鲜且几何一致，相机 200 → 800 ms 只代价 ~2–3 个点。（注意：连 k_l=1 的格子都低于 LiDAR-only，这个惩罚来自 *naive 50 ms 过期 LiDAR* 本身——E2 已证明它单独就会背刺——不应解读为"相机 200 ms 就伤不起"。）
- 结合 E2/E5/E6 的经验法则：不做补偿的管线里，融合栈中**任何**过期 LiDAR 都可能让融合不如纯 LiDAR；做了补偿后，融合能容忍几百毫秒的相机延迟，但 LiDAR 必须在 ~75 ms 以内。

## 5. 注意事项

- 单一官方 BEVFusion checkpoint，跨 checkpoint 稳健性未测。
- T1/E2 参考数字来自不同的共同子集（n = 5856），E6 为 n = 5719；实验内部对比精确，跨实验对比为近似。
- 相机延迟按每步约 100 ms 计（T1 语义）；LiDAR 每 sweep 约 50 ms（20 Hz）。
