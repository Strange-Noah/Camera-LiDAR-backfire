# T1B：自车一致的延迟相机输入 —— 回应第 16 节的标定悬而未决问题

**日期：** 2026-11-05
**状态：** 已完成 —— 全量推理 + 配对子集评测全部结束
**模型：** BEVFusion 相机–激光融合（官方 checkpoint），nuScenes val

## 1. 动机（悬而未决的问题）

在 T1 实验中，我们把当前相机图像替换为第 k 帧历史相机图，但**沿用当前帧的标定**
（内参 cam2img 和外参 lidar2cam）。这把延迟图像当作从当前自车位置拍摄的来处理——
错误的对应关系把自车运动和世界运动混在了一起。项目简报第 16 节留下的开放问题是：
历史帧是否应该**带上它自己那一刻的标定**（选项 B：自车一致的重放）。

T1B 实现了选项 B：历史图像连同它自己的 `cam2img`、`cam2ego`、`lidar2cam` 一起
喂给模型（lidar2cam 按 capture 从 `calibrated_sensor` 和 `ego_pose` 记录重建，
与 mmdet3d 关键帧数值完全一致，100 条 sanity check 最大绝对误差 5.7e-05）。
激光保持当前帧。此时残留的相机–激光错位纯粹来自真实的世界/物体运动——
这是对「延迟相机流」最诚实的仿真。

## 2. 实验设置

- 相机延迟 k ∈ {2, 5, 8}（prev 链步数）≈ 200 / 400 / 700 ms（实测）。
- 资格要求：6 个相机全部存在第 k 个同场景 prev capture：
  k = 2 / 5 / 8 时分别有 5869 / 5863 / 5719 个 val 样本。
- 历史图像：77128 张存于 /root/camhist_b（pkl 中用绝对路径引用）。
- 标定公式：`lidar2cam = inv(cam2ego) · inv(ego2global_cam) · ego2global_lidar · lidar2ego`。
- 配对评测：对 {融合 clean、LiDAR-only、T1 k2/k5/k8、T1B k2/k5/k8} 八个文件
  取共同子集，使用 nuScenes 官方指标。

## 4. 解读

**第二种情况成立——而且非常显著。** 让历史相机帧带上它拍摄时刻的标定（T1B），
在每个测试延迟下都几乎完全恢复了 T1 中看到的性能衰减：

- ~200 ms 时，T1B（0.6854）与 clean 基线（0.6869，−0.15 pt）基本不可区分；
  而 T1 此时已损失 1.6 pt。
- ~700 ms 时，T1B 仍只比 clean 低 0.85 pt，而 T1 下跌了 4.0 pt，并且**跌破了
  LiDAR-only 基线**（0.6470 < 0.6496）。同样的延迟下，T1B 的融合模型
  明显保持在 LiDAR-only 之上。

T1B − T1 的差距随延迟单调增大（+1.4 → +2.6 → +3.1 pt），这正是自车运动
误差的特征：延迟图像被当作从当前位置拍摄的时间越久，标定错位越大。

**对第 16 节问题的回答：** 标定的选择不是一个呈现细节——它决定了实验
测量的到底是什么现象。用当前帧标定（T1），测得的衰减主要由*人为的
自车运动错位*主导；用拍摄时刻一致的标定（T1B），模型对延迟图像表现出
惊人的鲁棒性（700 ms 内损失 ≤ 0.85 pt），残余的衰减测量的才是*真实的
内容陈旧*（世界/物体运动）。

**对论文的建议：** 把 T1B 作为时间错位实验的主要协议（它才是对延迟数据流
的诚实仿真），并用 T1 与 T1B 之差作为量化分解：~700 ms 时，观测到的
4.0 pt 衰减中约 3.1 pt 可归因于标定/自车运动错位，约 0.9 pt 来自内容陈旧。
此前报告的「融合反噬交叉点」（融合低于 LiDAR-only）在自车一致协议下消失了。

## 5. 注意事项

- T1B 的延迟（200/400/700 ms）在相机 prev 链上实测（12 Hz capture，按均值计）；
  单样本存在抖动。
- 跨实验的子集与早前 T1/E2 报告不同（那里 n = 5856）。
- 一个 val 场景（`n015-2018-11-21-19-21-35`）的大部分 sweep 在公共 blob 中缺失；
  mmdet3d 加载器会静默跳过缺失的 sweep，T1B 全部运行零加载失败完成
  （k8 拿到 5719/5719 条预测）。即便有影响，也在配对子集中被 T1/T1B/基线
  完全同等地共享。
- Pilot 验证：T1B 预测在 k5 资格的 5863 个样本上与 T1 100% 不同
  （框级对比），确认标定替换确实生效并传入了模型。
