# OCaMo operating rules

Follow ancestor project safeguards. The current user-authorized OCaMo policy supersedes historical branch routing: use noah/ocamo-baseline for original unweighted calibration and noah/ocamo-experiments for later authorized extensions. Read docs/ocamo/HANDOFF.md before work. Do not modify historical Rotation branches, main, teammate branches or the closed local preflight branch. Do not create task branches.

Keep large sensor data, CARLA archives and checkpoints remote. No local bulk downloads, paid resource creation/start, large remote downloads or inference without authorization. Preserve the official objective, optimizer, feature extraction and parameters; isolate necessary adaptations. Do not build an alternative estimator before the official example runs. No Conditional Weighting implementation is authorized. Never label unexecuted gates successful. Keep private raw logs outside Git and redact public reports.
